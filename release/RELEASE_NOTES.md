# E621Downloader v1.5.1

基于 v1.5.0 的界面修复版本。

## 本次更新

- 移除云母材质相关实现与设置项说明，窗口统一为纯色背景，深色模式不再发灰
- 修复通知提示条内部控件误用外框样式导致的排版错位，图标、文字与关闭按钮恢复对齐
- 浅色背景降低亮度，减少大面积白色的刺眼感

## 主要功能

- **发现页**：无需登录浏览 e621 推荐作品，点击查看大图
- **搜索下载**：多标签搜索、持久化/临时黑名单、最低评分、页数与每页数量设置
- **三种画质**：原图、采样图、预览图
- **下载管理**：实时进度、取消下载、MD5 去重、跳过已下载文件
- **账号与收藏**：用户名 + API Key 登录，收藏/取消收藏，批量收藏、拉黑、下载
- **黑名单**：添加后自动从发现、搜索、收藏中过滤
- **本地数据**：搜索历史、最近关键词（可配置条数）、清空缓存、打开配置目录
- **运行模式**：默认单机模式，一键切换在线模式，联网请求统一门禁
- **界面**：Windows 11 Fluent Design、深色/浅色/跟随系统、高 DPI 适配

## 下载

Windows 10 / Windows 11 64 位：下载 `E621Downloader.exe`，双击运行，无需安装 Python 或运行库。

## 使用提示

- 首次启动默认为单机模式，请前往「设置 › 运行模式」切换为在线模式。
- 登录与收藏需要 e621 账号及 API Key；未登录也可使用游客模式浏览与下载。
- 账号信息仅保存在本机 %USERPROFILE%\E6Dler\userdata.json ，请勿分享该文件。
